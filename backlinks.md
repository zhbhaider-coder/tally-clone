# Backlink plan — Tally clone (white-hat only)

**Rule (Zohaib's standing rule):** legitimate levers only. No paid links, no link farms, no spam, no scraped outreach, no automated submissions. Every listing below is a real directory/profile where a real product can be listed for free.

## Strategy
1. **Directories & startup listings** — free product listings with a link back. These are the fastest legitimate links for a new tool.
2. **Profiles that link out** — GitHub repo, dev profiles, product pages.
3. **Content that earns links** — the ANALYSIS.md findings (Tally's $6M ARR, the badge loop) and the clone itself are worth linking to from "free form builder" roundups.
4. **The badge loop** — every free published form links back to the clone homepage. This is the original's own distribution engine and it is white-hat by design: respondents click because the form is useful.

## What NOT to do
- Never buy links, never use link farms or PBNs, never mass-submit to hundreds of directories with spun descriptions, never scrape emails for outreach, never post the link in comments/forums where it is off-topic. One good link from a real directory beats fifty spammy ones, and spammy links can get the domain penalized.

## Measurement
- Track in Search Console (once verified): impressions for "free form builder", "Tally alternative", "create a form online free".
- Track badge click-throughs: add `?ref=badge` to the badge link later and count arrivals in analytics.
- Re-check this list monthly; drop any directory that stops linking out or turns paid-only.
